# Inventário da interface atual

## Shell global
- Cabeçalho fixo com marca Nocturna.
- Menu responsivo.
- Busca global.
- Links: Tags, Categorias, Arquivo, Sobre, FAQ, Contato e Privacidade/cookies.
- Barra de progresso de leitura.
- Rodapé com crédito, GitHub e acesso a Pensadores.
- Tema escuro de romantismo sombrio, com fundo quase preto, painéis escuros, vinho e tipografia serifada.

## Página inicial
- Hero/editorial.
- Contagem do acervo.
- Grade de publicações.
- Atalhos para índice completo e arquivo.
- Navegação entre Publicações, Séries, Categorias, Tags e Arquivo.
- Cartões com capa, favoritos e estado de leitura quando aplicável.

## Acervo
- Índice de artigos/publicações.
- Arquivo cronológico.
- Filtros e taxonomias.
- Categorias editoriais e interpretativas.
- Sistema extenso de tags.

## Leitura
- Conteúdo em coluna de leitura.
- Tipografia serifada e espaçamento amplo.
- Progresso fixo.
- Sumário quando disponível.
- Navegação entre capítulos/itens.
- Ilustrações SVG associadas às publicações.

## Séries
- Índice de séries.
- Capas.
- Árvore de capítulos.
- Breadcrumbs.
- Conteúdo de capítulo.
- Navegação anterior/próximo.

## Informacional
- Sobre.

- Privacidade e cookies.
