# Handoff para o segundo repositório

## Estado
A branch nocturna-novo foi criada a partir de main para manter o trabalho separado do Nocturna atual.

## Por que não existe um segundo repositório ainda?
A integração GitHub disponível nesta sessão não possui a operação administrativa de Create Repository. Ela permite branches, árvores, blobs, arquivos, commits, issues e pull requests, mas não a criação de um repositório vazio.

## Próximo passo
Criar um repositório com nome distinto, recomendado: Nocturna-Novo.

Depois, importar esta branch como ponto de partida do novo repositório. Não apagar nem renomear Nocturna.

## Critério de aceite
O novo repositório deve manter:
1. Todas as rotas públicas atuais.
2. Todo o acervo editorial.
3. Séries e capítulos.
4. Categorias e tags.
5. Busca.
6. Favoritos/estado de leitura.
7. Pensadores e genealogia canônica.
8. Validações e workflows.
9. Sitemap, manifest, robots e llms.
10. Deploy equivalente ao atual.

A interface deve continuar visualmente equivalente ao Nocturna atual antes de qualquer redesign.
