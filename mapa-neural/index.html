Como rastrear

  1. Comece por uma publicação e siga classified-as para categorias.
  2. Siga tagged-with para conceitos editoriais compartilhados.
  3. Siga semantically-related para artigos relacionados por categorias ou tags.
  4. Consulte dated e o arquivo para a dimensão temporal.
  5. Use o JSON para consumo por agentes, indexadores, buscadores e sistemas de recuperação semântica.

Preservação

Cada publicação contém seu registro completo em article.record. O grafo acrescenta relações; não resume, substitui ou apaga os campos da fonte.
